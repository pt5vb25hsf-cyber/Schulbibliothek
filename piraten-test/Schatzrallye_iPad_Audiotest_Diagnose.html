So testet ihr es

  1. Öffnet die Webseite in Safari über HTTPS.
  2. Ladet das Sprachmodell einmalig.
  3. Sprecht den angezeigten Text vollständig ins iPad.
  4. Prüft, ob die Aufnahme freigeschaltet wird.
  5. Versucht danach bewusst einen ganz anderen Text – er sollte abgelehnt werden.

Datenschutz und Grenzen

Lokale Berechnung: Die App übergibt das Audiosignal nur an das auf dem iPad laufende Sprachmodell. Der Code enthält keinen Audio-Upload.

Internet: JavaScript, Laufzeitdateien und Sprachmodell werden beim ersten Start von externen Servern heruntergeladen. Für den Schulbetrieb sollten diese Dateien später auf einem kontrollierten Schul-Webserver liegen.

Wichtig: Die Modellladung kann auf älteren iPads scheitern oder lange dauern. Ein Erfolg ist auf Safari ohne Gerätetest nicht garantiert.

Mikrofonzugriff benötigt eine HTTPS-Webadresse und Zustimmung der nutzenden Person. Beim Schließen der Seite werden hier keine Audiodateien dauerhaft gespeichert.
